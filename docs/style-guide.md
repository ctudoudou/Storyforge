# Storyforge Style 设计描述

## 当前权威 UI 基线

初版产品 UI 必须完全参考用户提供的 `AI 短剧生成平台.zip`。该压缩包中的页面布局、深色工作台基调、颜色、间距、组件密度、中文文案、按钮样式、标签状态、素材展示和交互结构，是当前最高优先级的视觉参考。

项目实现框架使用 Next.js。由于参考代码本身是 Vite/React 结构，迁移到 Next.js 时只允许做框架适配，例如路由、入口文件、静态资源路径、Client Component 标记和构建配置调整；不得擅自改变 UI 风格。任何视觉调整都必须通过后续独立版本迭代确认并记录。

## 视觉定位

Storyforge 的界面应呈现现代、清晰、沉浸但克制的创作工作台气质。整体参考 Apple 近年系统界面中的透明玻璃质感：轻盈的半透明层级、柔和背景模糊、精确留白、清晰文字对比，以及像内容浮在真实空间中的深度感。设计重点不是炫技，而是让用户在复杂的短剧生成流程中始终看清当前阶段、素材状态和下一步动作。

## 核心关键词

- 现代：布局简洁，组件少而明确，避免厚重边框和复杂装饰。
- 清晰：信息层级优先于视觉效果，关键状态、进度和操作必须一眼可读。
- 玻璃质感：使用半透明材质、背景模糊、细腻高光和轻阴影表达层级。
- 创作感：保留影像、角色、场景和时间线的视觉存在感，让界面像一个短剧制作空间。
- 专业感：整体安静、精准、有秩序，适合长时间创作和反复修改。

## 材质与层级

界面可以使用三层材质系统：

- 基底层：干净的浅色或深色背景，可带轻微冷暖渐变或极弱噪点，用于承载整体空间。
- 玻璃层：主要面板、侧栏、浮层和工具栏使用半透明背景、背景模糊、1px 低对比描边和柔和投影。
- 内容层：文字、缩略图、时间线、生成状态和操作按钮必须保持高对比度，不被玻璃效果削弱可读性。

玻璃效果应轻，不应变成强烈磨砂或高反光拟物。透明度、模糊和阴影只用于表达空间层级，不能干扰阅读。

## 色彩方向

默认色彩应以中性色为主，搭配少量富有创作感的强调色。

- 背景：白、雾灰、石墨黑或深蓝黑，根据产品主题选择明暗模式。
- 文字：主文字保持接近黑或白的高对比，辅助文字使用低饱和灰阶。
- 强调色：可使用冷青、湖蓝、银蓝或微暖琥珀作为生成、选中和主要行动的提示色。
- 状态色：成功、警告、错误、处理中要有稳定语义，不与品牌强调色混淆。

避免大面积紫蓝渐变、过度霓虹、单一蓝灰铺满全屏，以及让界面显得像普通 SaaS 模板的卡片堆叠。

## 排版

排版应像专业创作软件，而不是营销落地页。

- 字体使用现代无衬线系统字体，优先保证跨平台清晰度。
- 标题短而明确，用于定位当前工作阶段，例如“剧本解析”“角色资产”“场景镜头”“导出”。
- 正文和说明文字保持简短，解释范围、状态或下一步，不写宣传式文案。
- 数字、状态、时间码、镜头编号和版本号需要等宽或稳定宽度处理，避免布局跳动。

## 布局原则

Storyforge 的核心界面应围绕工作流组织，而不是围绕展示型卡片组织。

- 左侧或顶部提供阶段导航：输入、解析、角色、场景、分镜、合成、审阅、导出。
- 中央是主创作区域：剧本文本、角色板、场景画面、分镜时间线或预览播放器。
- 右侧可放置上下文检查器：参数、提示词、版本、素材来源、生成设置和审阅状态。
- 底部适合承载时间线、镜头列表、生成队列或导出进度。

每个区域都应有稳定尺寸和清楚边界。可使用玻璃面板，但不要把页面拆成大量孤立卡片。

## 组件语言

- 主按钮：用于生成、继续、导出等关键动作，颜色清晰但面积克制。
- 次按钮：用于预览、重试、复制、回滚、查看详情等辅助动作。
- 状态标签：显示解析中、待生成、已生成、需审阅、失败、已导出等流程状态。
- 素材缩略图：必须带稳定 ID、版本、来源阶段和审阅状态，便于追踪。
- 参数控件：模型、风格、比例、时长、镜头类型、声音和字幕设置应使用清楚的表单控件，不用含糊的自由文本替代。

图标应服务于识别和操作，不做装饰。按钮内图标需要有悬停说明或明确标签。

## 动效

动效应强调创作流程正在推进。

- 阶段切换使用轻微位移和淡入，帮助用户理解工作流前后关系。
- 生成过程使用低噪声进度反馈，例如流动高光、分段进度、素材逐步出现。
- 面板展开、参数修改、版本切换要快速顺滑，避免夸张弹性动画。
- 大型媒体预览可以使用细微缩放或光影过渡，增强影像感。

所有动效都应可感知但不抢戏，不能影响长时间使用的稳定感。

## 影像与资产呈现

因为 Storyforge 的核心是短剧生成，界面必须让角色、场景和镜头资产成为视觉主角。

- 角色资产应以一致比例展示，清楚标注角色名、版本、风格和生成状态。
- 场景图应强调地点、时间、情绪和镜头用途。
- 分镜和镜头列表应能快速比较前后画面、对白、时长和转场。
- 最终预览区应像轻量剪辑台，而不是普通文件播放器。

## 禁用方向

- 不做厚重拟物玻璃、强反光、高饱和霓虹边框。
- 不使用大量圆角卡片堆叠来替代信息架构。
- 不使用营销页式大标题来占据工作台首屏。
- 不让透明背景降低文字、状态、时间码或操作按钮的可读性。
- 不把 AI 生成过程包装成神秘感装饰，必须保持可追踪、可恢复、可审阅。

## 一句话风格描述

Storyforge 的界面是一套现代、清晰、带透明玻璃层次的 AI 影视创作工作台：它用轻盈材质和精确层级承载复杂生成流程，让用户能像管理专业制作项目一样追踪剧本、角色、场景、镜头和最终短剧。
